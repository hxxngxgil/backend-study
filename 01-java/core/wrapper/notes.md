# Wrapper Class (래퍼 클래스)

## 기본형의 한계

자바의 기본형(int, double 등)은 객체가 아니기 때문에  
객체 기능을 사용할 수 없다.

한계
- null 저장 불가능
- 컬렉션 사용 불가능
- 메서드 사용 제한

---

## 래퍼 클래스란

기본형을 객체로 감싸는 클래스이다.

기본형마다 대응되는 래퍼 클래스가 존재한다.

---

## 기본형과 래퍼 클래스

- byte → Byte
- short → Short
- int → Integer
- long → Long
- float → Float
- double → Double
- char → Character
- boolean → Boolean

---

## 래퍼 클래스 사용 이유

- 객체처럼 사용 가능
- 컬렉션 사용 가능
- 다양한 메서드 제공

---

## 자바 래퍼 클래스 특징

래퍼 클래스는 불변 객체이다.

즉, 내부 값을 변경할 수 없다.

---

## 박싱 (Boxing)

기본형 → 래퍼 클래스 변환

예시

Integer num = Integer.valueOf(10);

---

## 언박싱 (Unboxing)

래퍼 클래스 → 기본형 변환

예시

int value = num.intValue();

---

## 오토 박싱 (Auto Boxing)

자바가 자동으로 박싱을 처리한다.

예시

Integer num = 10;

→ 자동 박싱

---

## 오토 언박싱 (Auto Unboxing)

자바가 자동으로 언박싱을 처리한다.

예시

int value = num;

→ 자동 언박싱

---

## 래퍼 클래스 주요 메서드

### valueOf()

기본형 값을 래퍼 객체로 생성

예시

Integer.valueOf(10)

---

### intValue()

래퍼 객체를 기본형으로 변환

예시

num.intValue()

---

### parseInt()

문자열을 int로 변환

예시

Integer.parseInt("100")

---

### compareTo()

값 비교

예시

num1.compareTo(num2)

---

## 래퍼 클래스 성능

래퍼 클래스는 객체이기 때문에  
기본형보다 성능이 느릴 수 있다.

이유
- 객체 생성 필요
- 메모리 사용 증가
- 오토박싱/언박싱 발생

---

## 성능 주의점

반복문처럼 성능이 중요한 곳에서는  
기본형 사용이 더 효율적이다.

---

## 핵심 정리

1. 기본형은 객체 기능을 사용할 수 없다.
2. 래퍼 클래스는 기본형을 객체로 감싼다.
3. 래퍼 클래스는 불변 객체이다.
4. 박싱은 기본형 → 객체 변환이다.
5. 언박싱은 객체 → 기본형 변환이다.
6. 자바는 오토박싱과 오토언박싱을 지원한다.
7. 래퍼 클래스는 기본형보다 성능이 느릴 수 있다.
