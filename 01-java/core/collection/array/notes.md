# ArrayList

## 배열(Array)의 특징

배열은 같은 타입의 데이터를 연속된 메모리 공간에 저장하는 자료구조이다.

### 특징

- 순서를 유지한다.
- 중복을 허용한다.
- 인덱스로 접근한다.
- 크기가 생성 시점에 고정된다.

예시

int[] arr = new int[5];

---

## 배열과 인덱스

배열은 인덱스를 사용하여 원하는 위치의 데이터를 바로 조회할 수 있다.

예시

arr[0]
arr[1]
arr[2]

인덱스를 사용하므로 조회 속도가 매우 빠르다.

---

# 빅오(Big-O) 표기법

알고리즘의 성능을 나타내는 표기법이다.

대표적인 시간 복잡도

O(1)

- 데이터 개수와 관계없이 일정한 시간

O(n)

- 데이터 개수만큼 시간이 증가

---

# 배열의 데이터 추가

배열은 크기가 고정되어 있다.

따라서 공간이 부족하면

더 큰 배열을 생성한 뒤

기존 데이터를 모두 복사해야 한다.

단점

- 데이터 복사 비용 발생
- 크기 변경이 불편함

---

# ArrayList

ArrayList는 배열을 기반으로 만든 리스트이다.

배열의 장점은 유지하면서

크기를 동적으로 변경할 수 있다.

---

## 배열과 ArrayList 차이

배열(Array)

- 순서 O
- 중복 O
- 크기 고정

ArrayList(List)

- 순서 O
- 중복 O
- 크기 변경 가능

---

# 동적 배열(Dynamic Array)

ArrayList는 내부적으로 배열을 사용한다.

배열이 가득 차면

더 큰 배열을 생성하고

기존 데이터를 복사한다.

이를 동적 배열이라고 한다.

---

# 직접 구현하는 ArrayList

직접 구현하면서 다음 기능을 만들 수 있다.

- 데이터 추가(add)
- 데이터 조회(get)
- 데이터 수정(set)
- 데이터 삭제(remove)
- 크기(size)

---

# 제네릭 적용

ArrayList는 제네릭을 사용하여

다양한 타입을 안전하게 저장할 수 있다.

예시

ArrayList<String>

ArrayList<Integer>

컴파일 시 타입 검사가 가능하다.

---

# ArrayList 시간 복잡도(Big-O)

## 데이터 추가

### 마지막 추가

O(1)

빈 공간에 바로 저장한다.

---

### 앞 / 중간 추가

O(n)

뒤에 있는 데이터를 모두 이동해야 한다.

---

## 데이터 삭제

### 마지막 삭제

O(1)

마지막 요소만 제거한다.

---

### 앞 / 중간 삭제

O(n)

뒤의 데이터를 앞으로 한 칸씩 이동해야 한다.

---

## 인덱스 조회

O(1)

인덱스로 바로 접근한다.

---

## 데이터 검색

O(n)

처음부터 순차적으로 탐색한다.

---

# ArrayList 장점

- 조회 속도가 매우 빠르다.
- 사용이 간편하다.
- 대부분의 상황에서 좋은 성능을 제공한다.
- 가장 많이 사용하는 List 구현체이다.

---

# ArrayList 단점

- 앞이나 중간에 데이터를 추가하거나 삭제하면 성능이 떨어진다.
- 배열 복사가 발생할 수 있다.

---

# 핵심 정리

1. 배열은 순서를 유지하고 중복을 허용하지만 크기가 고정된다.
2. ArrayList는 배열 기반의 동적 리스트이다.
3. ArrayList는 내부적으로 배열을 사용한다.
4. 공간이 부족하면 더 큰 배열을 만들고 데이터를 복사한다.
5. 마지막 추가/삭제는 O(1)이다.
6. 앞이나 중간 추가/삭제는 O(n)이다.
7. 인덱스 조회는 O(1)이다.
8. 데이터 검색은 O(n)이다.
9. ArrayList는 제네릭을 사용하여 타입 안정성을 제공한다.
10. 실무에서는 List 구현체로 대부분 ArrayList를 사용한다.
