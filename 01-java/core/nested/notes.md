# Nested Class & Inner Class (중첩 클래스와 내부 클래스)

## 중첩 클래스란?

클래스 내부에 선언된 클래스를 중첩 클래스(Nested Class)라고 한다.

예시

class Outer {

    class Inner {
    }

}

---

## 중첩 클래스를 사용하는 이유

- 논리적으로 관련된 클래스를 묶을 수 있다.
- 캡슐화가 가능하다.
- 코드 관리가 편해진다.

---

## 참고

실무에서는 중첩 클래스와 내부 클래스라는 용어를 엄격하게 구분하지 않는 경우가 많다.

- 중첩 클래스(Nested Class)
  - 클래스 안에 선언된 모든 클래스

- 내부 클래스(Inner Class)
  - 중첩 클래스의 한 종류

실무에서는 둘 다 비슷한 의미로 사용하는 경우가 많다.

---

# 중첩 클래스 종류

1. 정적 중첩 클래스 (Static Nested Class)
2. 내부 클래스 (Inner Class)
3. 지역 클래스 (Local Class)
4. 익명 클래스 (Anonymous Class)

---

## 정적 중첩 클래스

static이 붙은 중첩 클래스

예시

class Outer {

    static class Nested {
    }

}

---

## 특징

- 바깥 클래스의 인스턴스 없이 생성 가능
- static 멤버 사용 가능
- 바깥 객체 참조 없음

---

## 정적 중첩 클래스 활용

외부 클래스와 관련은 있지만

외부 객체 정보가 필요 없는 경우 사용한다.

---

## 내부 클래스 (Inner Class)

static이 없는 중첩 클래스

예시

class Outer {

    class Inner {
    }

}

---

## 특징

- 바깥 클래스 객체가 반드시 필요
- 바깥 객체 참조 가능
- 바깥 클래스 멤버 접근 가능

---

## 내부 클래스 활용

외부 객체와 강하게 연결된 기능을 구현할 때 사용한다.

---

## 같은 이름의 바깥 변수 접근

내부 클래스에서 같은 이름의 변수가 존재하면

가까운 범위의 변수가 우선된다.

예시

value

this.value

Outer.this.value

---

## 지역 클래스 (Local Class)

메서드 내부에서 선언되는 클래스

예시

void method() {

    class LocalClass {

    }

}

---

## 특징

- 지역 변수처럼 동작
- 선언된 메서드 안에서만 사용 가능
- 외부에서 접근 불가

---

## 지역 변수 캡처

지역 클래스는 자신이 선언된 메서드의 지역 변수에 접근할 수 있다.

이를 지역 변수 캡처(Capture)라고 한다.

---

## 지역 변수 캡처 제약

지역 클래스가 사용하는 지역 변수는

반드시

- final
또는
- 사실상 final(Effectively Final)

이어야 한다.

---

## 사실상 final

final 키워드가 없어도

값이 한 번만 할당되고 변경되지 않으면

사실상 final로 간주한다.

예시

int num = 10;

→ 이후 변경하지 않음

→ 사실상 final

---

## 이유

지역 변수는 메서드 종료 시 스택에서 제거된다.

하지만

지역 클래스 객체는 계속 살아있을 수 있다.

그래서 자바는 안전성을 위해

변경되지 않는 값만 캡처하도록 제한한다.

---

## 익명 클래스 (Anonymous Class)

이름이 없는 클래스

클래스를 한 번만 사용할 때 주로 사용한다.

예시

Runnable runnable = new Runnable() {

    @Override
    public void run() {
        System.out.println("run");
    }

};

---

## 특징

- 클래스 선언과 객체 생성을 동시에 수행
- 재사용 불가
- 코드가 간결해짐

---

## 익명 클래스 활용

- 이벤트 처리
- 콜백 구현
- 인터페이스 구현

---

# 변수의 생명주기

## 클래스 변수 (static 변수)

생성 시점
- 클래스 로딩 시 생성

소멸 시점
- 프로그램 종료 시

저장 위치
- 메서드 영역

생명주기가 가장 길다.

---

## 인스턴스 변수

생성 시점
- 객체 생성 시

소멸 시점
- 객체가 GC 대상이 될 때

저장 위치
- 힙 영역

---

## 지역 변수

생성 시점
- 메서드 실행 시

소멸 시점
- 메서드 종료 시

저장 위치
- 스택 영역

생명주기가 가장 짧다.

---

# 핵심 정리

1. 클래스 안의 클래스를 중첩 클래스라고 한다.
2. 정적 중첩 클래스는 바깥 객체 없이 사용 가능하다.
3. 내부 클래스는 바깥 객체가 필요하다.
4. 지역 클래스는 메서드 내부에 선언된다.
5. 지역 클래스는 지역 변수 캡처가 가능하다.
6. 캡처하는 지역 변수는 final 또는 사실상 final이어야 한다.
7. 익명 클래스는 이름 없는 일회용 클래스이다.
8. 클래스 변수 > 인스턴스 변수 > 지역 변수 순으로 생명주기가 길다.
